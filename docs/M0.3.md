# M0.3 — bounded conversation context

M0.3 adds caller-supplied short-term conversation history without making BotAI
a persistent conversation database.

`POST /v1/chat` accepts an optional `history` array before the current
`message`. History entries may only use `user` or `assistant` roles.

Limits:

- maximum 20 history messages;
- maximum 4096 bytes per history/current message;
- system-role history is rejected;
- BotAI does not persist history in M0.3.

The calling bot owns conversation scope and retention. It may choose context per
network/channel/nick or another policy appropriate to that bot. BotAI resolves
the expert system prompt itself, then passes the bounded history to the provider.

This design prevents callers from replacing the expert system role and avoids
creating a hidden cross-bot memory store. Server-side sessions, automatic
routing, summarization and long-term memory are future work.
