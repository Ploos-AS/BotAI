# M0 — service skeleton

M0 establishes the standalone-safe BotAI boundary.

Acceptance criteria:

- BotAI builds as a standalone Go service.
- `GET /healthz` reports service/provider status.
- `GET /v1/experts` exposes the initial general, IRC and Amiga profiles.
- `POST /v1/chat` validates bounded JSON requests and routes through a provider interface.
- The deterministic echo provider allows tests without network/model dependencies.
- Unit tests cover health, successful expert routing and unknown experts.
- CI runs test, vet and build.
- Alpine OCI image builds and runs as an unprivileged user.
- BotAI is not a runtime dependency of any IRC bot.

M0 deliberately does not claim LLM quality, persistent conversation memory,
RAG, PBMP management, or production authentication. Those belong to later milestones.
