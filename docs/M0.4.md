# M0.4 — deterministic expert routing

M0.4 adds optional automatic expert selection.

Clients may send `"expert":"auto"`. BotAI then applies a local,
deterministic classifier to the current message and selects `irc`, `amiga`,
or `general`.

Rules:

- an explicitly named expert always wins;
- auto-routing makes no additional LLM/API call;
- a specialist is selected only when its domain has a unique positive match;
- ambiguous ties and unknown subjects fall back to `general`;
- the selected expert ID is returned in the normal chat response.

The initial router is deliberately small and explainable. It is not intended as
semantic classification. More domains and optional model-assisted routing can
be added later without changing the public `expert:"auto"` contract.
