# M0.7 — runtime expert reload and status

When `BOTAI_EXPERTS_FILE` is configured, BotAI can reload that same file at
runtime by receiving `SIGHUP`.

A reload is validated completely before the active registry is replaced.
Invalid reloads are logged and the last valid registry remains active. Readers
use a consistent registry snapshot while reloads occur.

```sh
kill -HUP <botai-pid>
```

M0.7 also adds `GET /v1/status`, returning service status, provider name and
the current expert count. It is intentionally read-only and does not expose
system prompts, route terms, API keys or configuration paths.

BotAI does not require PBMP or BotWeb for reload or status. Remote mutation and
management authentication are intentionally outside M0.7.
