# M1.0 — bot integration reference client

M1 starts integration work without coupling IRC bot cores to BotAI.

`pkg/botaiclient` is the Go reference implementation of the BotAI v1 client
contract. It provides:

- API compatibility check through `GET /v1/version`;
- expert discovery through `GET /v1/experts`;
- chat through `POST /v1/chat`;
- caller-supplied bounded history;
- bounded response decoding and HTTP timeout;
- status-only upstream errors that do not copy provider/server response bodies.

The client is optional. Engo may import it directly because Engo is Go.
LuCa and AmBot should implement equivalent native HTTP adapters rather than
embedding Go or depending on this package.

Bot integration rule remains unchanged: failure to construct, connect to or
use a BotAI client disables only AI-specific features. It must never prevent
the IRC bot core from starting or continuing normal IRC operation.
