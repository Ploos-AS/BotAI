# M0.1 — real provider boundary

M0.1 adds the first real model-provider adapter while retaining deterministic,
offline qualification.

## Provider selection

`BOTAI_PROVIDER=echo` remains the default.

For an OpenAI-compatible chat-completions endpoint:

```sh
BOTAI_PROVIDER=openai-compatible
BOTAI_BASE_URL=http://127.0.0.1:11434/v1
BOTAI_MODEL=my-model
BOTAI_API_KEY=
go run ./cmd/botai
```

The adapter targets the widely implemented `/chat/completions` shape beneath
the configured base URL. This permits local or remote compatible services
without coupling BotAI's public API to a model vendor.

## M0.1 acceptance

- provider is selected explicitly by configuration;
- echo remains the safe/default provider;
- missing provider configuration fails at BotAI startup, not inside IRC bots;
- API keys are read from environment only and never returned by BotAI;
- provider HTTP requests have a finite timeout;
- non-success upstream responses fail only the AI request;
- tests use an in-process mock HTTP server and require no external model/API.
