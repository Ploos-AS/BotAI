# M0.5 — data-driven expert registry

M0.5 expands BotAI's expert set and makes deterministic routing data-driven.

Profiles now carry their own private routing terms alongside their public
description and private system prompt. The generic router iterates the registry
instead of containing domain-specific branches.

Experts:

- `general`
- `irc`
- `amiga`
- `linux`
- `networking`
- `security`
- `c64`
- `atari`

Routing remains conservative: only one unique positive best match selects a
specialist. A tie or no match selects `general`. Explicit expert selection
continues to bypass automatic routing.

Route terms and system prompts are implementation details and are not exposed
by `GET /v1/experts`.
