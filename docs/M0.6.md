# M0.6 — external expert configuration

BotAI keeps its built-in expert registry as the zero-configuration default.

Set `BOTAI_EXPERTS_FILE` to a JSON file to replace the built-in registry at
process startup:

```sh
BOTAI_EXPERTS_FILE=/etc/botai/experts.json go run ./cmd/botai
```

See `examples/experts.json`.

Validation is fail-fast and atomic. The external registry must contain at least
one expert and must define `general`. IDs are normalized to lowercase;
`auto` is reserved; duplicate IDs, unknown JSON fields, empty descriptions,
and empty system prompts are rejected. Empty routing terms are discarded.

If loading fails, BotAI exits before serving requests. IRC bots remain
independent because BotAI itself is still an optional service.

M0.6 intentionally loads configuration only at startup. Runtime reload and
remote management are later concerns.
