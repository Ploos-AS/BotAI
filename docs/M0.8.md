# M0.8 — privacy-first observability

M0.8 adds request observability without logging IRC conversation content.

Every HTTP response includes `X-Request-ID`. A caller-supplied request ID is
preserved when it is at most 128 bytes; otherwise BotAI generates one.

Request logs contain only request ID, HTTP method, path, status and duration.
They do not contain chat messages, history, system prompts, provider responses,
nicknames or channels.

`GET /metrics` exposes Prometheus-compatible aggregate counters:

- `botai_http_requests_total`
- `botai_chat_requests_total`
- `botai_chat_errors_total`
- `botai_chat_duration_seconds_sum`
- `botai_chat_duration_seconds_count`

Metrics deliberately use no user-, channel-, expert-, prompt- or
conversation-derived labels. The implementation adds no external Go
dependency.
