# M0.2 — expert profiles

M0.2 makes expert behavior a BotAI concern rather than a model-provider concern.

Each expert profile has:

- a stable ID used by bot integrations;
- a public description returned by `GET /v1/experts`;
- a private system prompt supplied to the selected model provider.

Initial profiles are `general`, `irc`, and `amiga`.

Provider adapters do not construct domain prompts. They receive the resolved
system prompt in the internal request. This keeps expert policy independent of
OpenAI-compatible, local, or future provider implementations.

System prompts are intentionally not returned by the public expert-list API.
They are implementation policy, not remote bot configuration.

M0.2 remains stateless. Conversation memory, automatic expert routing,
multi-expert collaboration and RAG are future milestones.
